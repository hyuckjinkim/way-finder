## P1 — 네이버/카카오 수준 체감
- **검색**: 지도중심/GPS 좌표 전송(지금 항상 시청 기준) · 짧은 한글어에 `+역` 병렬 검색해 역 우선(강남→강남역, 홍대→홍대입구역; 구디역·고터는 카카오가 이미 처리 → 별칭 사전 불필요) · 주소검색 폴백(판교로 235 = 0건) · 결과에 거리·업종 표시 · 최근 검색(localStorage) · 앱 내 쿼리 메모리 캐시
- **경로 표시**: ODsay subwayCode/busType → 노선 공식색(`TransitMeta.lineColor`) · 출발/도착/환승 마커 · 구간 막대+노선색 칩 · 대안 경로 목록(ODsay path[] 전부; 소요·도착시각·요금·환승) · `loadLane`으로 실제 노선 모양
- **화면 가림**: 반투명은 탈락(지도도 글자도 흐림). **네이버식 바텀시트**(스냅 30/60/90%, 손잡이) 채택 — 장소 상세를 풀스크린 모달 대신 시트로, 경로입력은 내용 높이(~40%)로. 데스크톱은 떠 있는 카드형 패널 + 접기
- **흐름**: 출발지=내 위치 기본 · 출/도착 swap · 장소 시트에 [출발][도착] · 내 위치 파란 점 · 위치 권한 거부 안내
- **속도**: 모바일 Lighthouse 59 / LCP 11.6s(스로틀) — 엔트리 JS 3.3MB(br 0.8MB) 단일 번들 → 라우트 지연로딩 · 카카오 SDK `preconnect`+head 조기 로드 · `_headers`로 해시 자산 1년 immutable
