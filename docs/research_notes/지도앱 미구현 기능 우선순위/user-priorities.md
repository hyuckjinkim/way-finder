## Q1. 시장 점유율·MAU(2024–2026)와 앱별 선택 이유

### Takeaway
네이버지도가 압도적 1위다(2026년 8월 MAU 약 3,080만, 설문 이용률 79%). 그 뒤로 TMAP(약 1,500만, 운전 중심)과 카카오맵(약 1,250–1,350만, 실시간 대중교통·로컬)이 2위권을 다투고, 구글지도(약 1,000만, 외국인·해외여행)가 따른다. 네이버는 "장소 정보·리뷰·예약 올인원", 카카오는 "초정밀 버스·지하철", TMAP은 "내비게이션", 구글은 "해외/외국인 + 장소 검색"으로 포지셔닝이 갈린다.

### Inferences
- 한국 사용자의 기본 멘탈 모델은 네이버지도다. 카카오 이용자 상당수는 네이버와 병행해 쓰는 것으로 보인다(중복응답 합계 176%). 소형 웹앱은 네이버/카카오의 UI 관례(출발·도착 입력, 경로 카드 형식)를 따를 때 학습 비용이 가장 낮다.
- TMAP은 운전 중심이라 대중교통·도보 웹앱의 직접 경쟁자는 아니다. 경쟁 축은 네이버(장소 정보)와 카카오(실시간 대중교통)다.
- 구글지도 성장은 외국인·해외여행 수요가 견인한다. 영문 UI·다국어 지원은 차별화 여지가 될 수 있다(우선순위는 타깃 사용자에 따라 정한다).

### Gaps
- 성별·연령별로 "앱 선택 이유"를 직접 물은 2024–2026년 공개 설문(오픈서베이, 와이즈앱 등)은 찾지 못했다. "네이버=리뷰/예약, 카카오=대중교통" 구분은 회사 전략과 기사 해석에 근거한 것이지 사용자 설문 결과가 아니다.
- TMAP의 모바일인덱스 원수치는 1차 출처로 확인하지 못했다(블로그 재인용). 시장점유율(%) 형태의 공식 수치도 없다.

## Q2. 가장 많이 쓰는 기능과 불만(pain point)

### Takeaway
기능 사용 실태를 비율로 보여주는 최신 공개 설문은 엠브레인 2026년 조사 하나뿐이었다. 여기서 장소 저장·여행 경로 계획(63.9%), 만남 장소를 함께 고르기(53.5%), 저장 목록 재활용(51.3%)이 상위였다. 최대 불만은 오래된 장소 정보(41.6%)와 광고·협찬 리뷰(37.9%)였다. 대중교통 시간 정확도는 체계적 측정 자료가 없고 기사 사례 수준의 증거만 있다.

### Cited Findings

- 55.6%는 포털 검색보다 지도앱을 켜서 주변을 탐색하는 쪽이 더 익숙하다고 답했다. — [다음 2026-08-04](https://v.daum.net/v/20260804101528061), [i-boss](https://www.i-boss.co.kr/ab-2877-17759)
- 63.9%가 여행할 때 장소를 저장하고 경로를 계획한다. — [다음 2026-08-04](https://v.daum.net/v/20260804101528061)
- 51.3%가 가고 싶은 곳을 저장해 두었다가 그 지역에 갈 때 저장 목록을 활용한다. — 동일 출처
- 53.5%가 친구·지인과 만날 장소를 정할 때 지도를 함께 본다(공유·협업 수요). — 동일 출처
- 98.4%가 지도앱의 장소 정보와 길안내를 신뢰한다. — 동일 출처
- 49.0%가 AI 추천·요약이 좋아지면 기존 검색엔진을 대체할 수 있다고 본다. — 동일 출처

- 승하차 알림, 하차까지 남은 역 수, 열차 출입문 위치, 출구 번호, iOS 지하철 실시간 길안내. — [ITWorld](https://www.itworld.co.kr/article/3556335/)

### Inferences
- 소형 웹앱에서 효과 대비 비용이 큰 순서(추론): ① **장소 저장/즐겨찾기 목록**(63.9%·51.3% 근거) → ② **링크 공유**(53.5%의 "함께 보며 장소 정하기", 웹은 URL 공유가 자연스러움) → ③ **실시간 버스/지하철 도착 정보**(카카오의 핵심 차별점, 공공 API 의존).
- "광고·협찬 리뷰"와 "광고가 지도 기능을 가리는 개편"에 대한 불만은 광고 없는 단순 UI 자체가 차별점이 될 수 있음을 뜻한다. 대중교통 길찾기를 첫 화면 1순위로 두는 것은 네이버가 '발견/예약' 우선으로 재편하면서 생긴 틈을 겨냥한다.
- "오래된 장소 정보"(41.6%)는 데이터 소스(장소 API)의 최신성 문제다. 직접 해결할 수는 없으므로 정보 출처·갱신일 표기나 "정보 수정 제안" 링크 정도가 현실적이다.
- 도착 시각을 숫자로 보여주는 것만으로는 지연을 놓친다(MT 사례). 실시간 차량 위치를 시각화하면 신뢰를 얻는 데 도움이 되지만 구현 비용이 높아 후순위 후보다.

### Gaps
- 오픈서베이·와이즈앱·KISA 등의 "지도앱 기능별 이용률" 설문(예: 대중교통 길찾기 몇 %, 실시간 버스 몇 %)은 2024–2026년 공개 자료로 찾지 못했다. 기능별 순위는 엠브레인 조사와 회사 발표에서 간접 추론했다.
- 앱스토어 리뷰를 체계적으로 요약한 자료(느린 로딩, 복잡한 UI 등 불만 빈도)는 찾지 못했다.
- 대중교통 도착 시간 정확도를 독립적으로 측정한 연구도 찾지 못했다.

## Q3. 2024–2026 네이버지도·카카오맵 주요 신기능과 반응

### Takeaway
두 회사 모두 (1) 실시간 대중교통 시각화, (2) AI 장소 추천, (3) 발견·예약·시즌 큐레이션으로 체류시간을 늘리는 방향으로 움직였다. 대중교통 실시간화(카카오 초정밀 지하철)는 언론 반응이 긍정적이었다. 반면 위치공유(카카오 친구위치)는 감시 우려로 논란이 됐고, 네이버의 발견/광고 우선 개편은 일부 커뮤니티에서 반발이 나왔다.

## Q4. 웹(비앱) 지도 이용: 데스크톱·모바일 웹에서 무엇을 하나

### Takeaway
PC·모바일 웹 지도 이용 비중을 보여주는 2024–2026년 공신력 있는 수치는 찾지 못했다. 정성적으로는 "출발 전 PC에서 전체 경로·코스 검토 → 이동 중 앱 실시간 안내"라는 분업 패턴이 확인된다. 웹 전용 강점으로 도보 코스 만들기·GPX·링크 공유가 언급된다.

### Cited Findings
- 네이버지도 길찾기 웹(map.naver.com/p/directions)은 PC·모바일 브라우저 모두에서 열린다. PC에서 경유지를 최대 5개까지 추가할 수 있다. 한 안내글은 "출발 전 PC로 전체 경로를 검토하고 이동 중엔 앱으로 실시간 안내"를 권장한다(개인 블로그, 2026년 10월 기준 작성). — [foxcg](https://foxcg.com/naver-directions/)
- 네이버지도 도보 '코스 만들기'는 PC 웹에서만 지원되고 모바일 앱에서는 지원되지 않는다. 저장한 코스는 GPX로 내려받거나 링크로 공유할 수 있고, 받은 사람이 자기 목록에 저장할 수 있다(블로그). — [funissu](https://funissu.com/?p=19204)
- 카카오맵은 모바일 앱의 자동차 경로비교를 PC 웹으로 확대했다(날짜 미확인, 2024년 이전 가능성 높음). 회사는 앱과 웹의 기능 패리티를 유지하는 방향으로 보인다[회사 발표]. — [카카오](https://www.kakaocorp.com/page/detail/7696)
- 엠브레인 조사에서 63.9%가 여행 시 장소를 저장하고 경로를 계획한다고 답했다. PC·모바일 구분은 없다. — [다음 2026-08-04](https://v.daum.net/v/20260804101528061)
- [오래된 데이터, 2011년] 네이버는 당시 PC 지도 점유율 70%를 주장했다. 현재 상황 판단에는 쓰지 말 것. — [네이버 보도자료](https://navercorp.com/media/pressReleasesDetail?seq=28482)

### Inferences
- 모바일 앱 MAU가 수천만 규모이고 "지도앱을 켜서 탐색"이 일반화된 점(55.6%)을 보면, 웹 지도의 역할은 (a) 데스크톱에서 미리 계획하기와 (b) 앱 설치 없이 공유 링크로 열기에 가까울 가능성이 높다.
- 그렇다면 웹앱의 우선 기능은 다음과 같다.
  - 길찾기·장소 상태를 URL에 담아 공유하거나 북마크하는 기능(딥링크)
  - 데스크톱의 넓은 화면을 쓰는 경로 비교·여러 경유지·저장 목록
  - 모바일 웹에서는 링크로 들어온 사용자가 바로 결과를 보는 빠른 첫 로딩
  - "네이버/카카오 앱에서 열기" 같은 앱 연계 버튼(URL 스킴)은 실시간 안내를 대형앱에 넘기는 저비용 대안이다. 참고: [NCloud Maps URL scheme 문서](https://guide.ncloud-docs.com/docs/application-maps-url-scheme-vpc)
  - 이 목록은 추론이며 검증된 사용 데이터가 아니다.

### Gaps
- map.naver.com·map.kakao.com의 웹 트래픽(UV/PV), PC·모바일 웹 비중, 웹에서 가장 많이 쓰는 기능에 대한 공개 통계를 찾지 못했다(KISA 인터넷이용실태조사에도 지도 웹·앱 구분 항목은 확인되지 않음).
